# freestep

Projeto principal do Free Step. Repositório privado.

| Pasta | O que é |
|---|---|
| `time-brasil/` | site do Free Step Brazil Team (WordPress: tema, plugins, docs e ferramentas) |
| `forward/` | Forward: liga (spec e motor de pontuação), Instagram (fila, legendas, publora) e site futuro |

O `forward/` veio de `mdds1/forward`, com o histórico. Os vídeos do Instagram ficam fora do git,
em `~/trabalho-video/instagram`. Credenciais do WordPress ficam em `~/.config/segredos/`, fora do git.
